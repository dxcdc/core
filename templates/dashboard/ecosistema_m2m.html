Como Funciona a Integração entre Seus Portais (*.cdc.org.br)

O **CDC Core** atua como o servidor central de dados e autenticação para todos os microsserviços do seu domínio. Qualquer outra aplicação sua (Flask, Django, Node.js) que precise consultar os dados do Google Workspace ou validar tokens de acesso pode se conectar ao Core usando o padrão seguro de **Header de Autorização M2M**.

1
Variável de Ambiente

Adicione a chave INTERNAL_M2M_API_KEY no arquivo .env da sua aplicação cliente.

2
Cabeçalho HTTP

Em todas as requisições HTTPS para o Core, inclua o header X-API-Key: <sua_chave>.

3
Resposta em JSON

O Core valida a chave instantaneamente e entrega os dados limpos em formato JSON.

Exemplos de Integração Prática
import os
import requests

API_KEY = os.getenv("INTERNAL_M2M_API_KEY", "sua-chave-aqui")
URL = "https://core.cdc.org.br/api/internal/workspace/data/"

def consultar_cdc_core():
    headers = {"X-API-Key": API_KEY}
    res = requests.get(URL, headers=headers)
    if res.status_code == 200:
        return res.json()["data"]
    return None
const axios = require('axios');

async function consultarCdcCore() {
  const url = 'https://core.cdc.org.br/api/internal/workspace/data/';
  const apiKey = process.env.INTERNAL_M2M_API_KEY;

  const res = await axios.get(url, {
    headers: { 'X-API-Key': apiKey }
  });
  return res.data;
}
